# MeshOk

Просмотрщик 3D-моделей в браузере (STL, OBJ, PLY, GLB/GLTF) с шерингом и загрузкой по ссылкам со сроком хранения.

- Живая версия: https://meshok.is-a.dev (и https://meshok.497c51aab268e25d4d56.workers.dev)
- Всё считается локально в браузере; загрузка по ссылке — через Cloudflare Worker + KV с авто-удалением по TTL.

Зеркало GitHub Pages. API указывает на воркер MeshOk.
